# 内容发布边界

## 可以提交

- 本仓库脚本、Schema、操作文档和测试数据。
- 作者原创文章、原创笔记。
- 具有明确开放许可或已获得再分发授权的材料，并保留来源与许可说明。
- 自行撰写、无真实业务数据的示例。

## 不提交

- 第三方文章全文、付费内容、仅供个人阅读的剪藏。
- 公司文档、客户信息、聊天记录、截图、令牌、Cookie、运行日志。
- 本地编译产物和状态文件；它们可能间接包含不应公开的原文。

## 发布前检查

1. 运行 `git status --ignored --short`，确认私有目录仍被忽略。
2. 使用 `git diff --cached --check` 检查待提交内容。
3. 在 GitHub 的提交文件列表中再次确认没有 raw 原文、生成页、日志和密钥。
4. 如果无法确认某份内容是否可再分发，默认不提交，只保留链接、作者、发布日期和自己的摘要。
