# Agent 评测样例：先定义可复现的失败，再讨论能力

Agent 评测最容易翻车的地方，不是模型分数低，而是任务、环境、轨迹和评分规则没有固定。

一个最小评测单元至少应包含：任务输入、可复现环境、允许工具、执行轨迹和评分器。只有把失败样本也保存下来，后续回归才知道系统究竟改善了什么。

## 最小验证动作

1. 用同一任务重复运行，确认环境和输入没有漂移。
2. 保存成功与失败轨迹，不只保存最终答案。
3. 让评分规则能指出失败发生在检索、规划、调用工具还是最终断言。

这份示例仅用于演示概念提取、Wiki 页面生成和互链，不包含真实业务数据。
